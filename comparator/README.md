# Checking the main theorems with Comparator

Comparator (built into Lake as `lake comparator` since Lean `v4.35.0`; formerly
[leanprover/comparator](https://github.com/leanprover/comparator)) checks the proofs against a
trusted statement:

* `Challenge.lean` (repository root) states the main theorems with `sorry`. Everything before them
  is a verbatim copy of `Cgt/Statement.lean`, generated by `scripts/gen_challenge.py`, and uses
  Lean core only. It defines short games and Conway's order, infinitesimals, the rules of Toads and
  Frogs, the starting positions `Tᵃ□ᵇFᵃ`, Erickson's Conjecture 5 (`Conjecture5`) and the cases left
  open here (`OpenCases`: `a ≥ 3`, `b ≥ 4`, `2a + b ≥ 13`).
* `Solution.lean` imports `Cgt.Conjecture5`, which proves them.
* `config.json` lists the two theorems and permits only `propext`, `Quot.sound` and
  `Classical.choice`:
  * `Cgt.conjecture5_of_openCases : OpenCases → Conjecture5`: every case outside `OpenCases` is
    proved;
  * `Cgt.not_infinitesimal_3_2`: the exception `(3, 2)` is genuine.

Comparator checks three things. The declarations in the theorem statements, and everything they
use, must be the same in both environments. The proofs must use only the permitted axioms. The
kernel must accept the `Solution` environment when it is replayed.

What you trust: `Challenge.lean` (that its definitions mean what they should, and that
`OpenCases` describes the open cases), the lakefile, and the tools (Lake's comparator, the
exporter, `bwrap`, the Lean kernel). Nothing else in the repository needs to be read.

The results that use `native_decide` (the column `b = 4`, its values, and `T⁶□¹²F⁶`) are not
covered: each `native_decide` adds an axiom that the permitted list excludes. They are built with
`lake build CgtNative`.

## Running it

From the repository root, with `bubblewrap` installed (it needs unprivileged user namespaces or a
setuid-root `bwrap`):

```sh
lake build
lake comparator --config comparator/config.json
```

After changing `Cgt/Statement.lean`, regenerate the challenge with
`python3 scripts/gen_challenge.py`.
